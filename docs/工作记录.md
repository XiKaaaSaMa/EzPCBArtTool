# 工作记录

> 每一轮开发**结束时**追加一行：日期 + **署名（GitHub 账户 id）** + 结论。
> 详细叙述仍写在 `PROGRESS.md`；这里只做「谁、什么时候、做到哪」的索引，
> 方便协作者一眼看出这一轮是谁推进的、有没有值得对接的东西。
>
> ⚠️ **为什么不靠 git 作者署名**：本仓库的提交作者统一是
> `PCB Art Board Tool <pcbart@localhost>`，**不含个人信息**（这是刻意的，
> 见 `docs/PACKAGING.md` 与 `.gitattributes` 的历史）。
> 所以「谁做的」写在这里，而不是写进 git 身份 —— 两件事分开，
> 换机器、换协作者都不会把私人邮箱带进历史。

---

## 署名规则

- 用 **GitHub 账户 id**（不是昵称、不是 git 的 `user.name`），
  因为 id 是稳定的、可 @ 到的
- 一行一轮：`| 日期 | @id | 一句话结论 | 测试基线 |`
- 多个人参与就写多个 id：`@a、@b`
- **AI 协作者也记在驱动它的人名下**，不单独署名
- **协作者第一次 push 时自己署名**：不用事先报备 id，
  在下面记录表加一行、写你自己的 GitHub 账户 id（`@你的id`）即可
