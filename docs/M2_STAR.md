# 五角星板框（异形板框验证）

> 生成文件：`out/m2_star5_edge30.epro2`
> 画法：折线工具，属性为**线条自由角度**

---

## 一、关于"线条自由角度"

规范里确认了它的含义——这是 `PREFERENCE` 记录的 `routingCorner` 字段，
表示绘制时的走线拐角约束模式：

| 取值 | 含义 |
|---|---|
| `"L45"` | 线条 45 度 |
| `"L90"` | 线条 90 度 |
| `"R45"` | 圆弧 45 度 |
| `"R90"` | 圆弧 90 度 |
| **`"L"`** | **线条自由角度** |
| `"R"` | 圆弧自由角度 |

**关键点：这是编辑器的绘制偏好，不是图元自身的几何数据。**

图元里存的是绝对顶点坐标，无论绘制时用什么模式，落盘后都是一样的坐标值。
所以"自由角度"意味着顶点可以停在任意角度上——五角星需要精确的 36° 递增，
正是自由角度模式的用途。生成的文件里 `routingCorner` 已设为 `"L"`。

## 二、几何推导

五角星是十边形：5 个外顶点与 5 个内凹顶点交替。经典五角星的内凹顶点
**就是五角星五条线的交点**，所以内半径不是自由参数，由形状本身锁死。

### 内半径

解交点位置得到：

```
r = R · cos(2π/n) / cos(π/n)
```

n=5 时：

```
r = R · cos72° / cos36° = R / φ²  ≈ 0.381966 R
```

（φ = 1.618… 是黄金比。外半径比内半径大 φ 倍，这是五角星的标准比例。）

### 外半径

内半径锁定后，一条边（连接相邻的外顶点与内顶点，两者圆心角相差 π/n）
的长度为：

```
L = R · tan(π/n)
```

反解，边长为 30 mm 时：

```
R = 30 / tan36° = 41.291458 mm
r = R / φ²     = 15.771933 mm
```

### 实际尺寸

| 项目 | 数值 |
|---|---|
| 外半径 | 41.291458 mm |
| 内半径 | 15.771933 mm |
| 边长（全部 10 条） | 30.000000 mm |
| 周长 | 300.0000 mm |
| 外形包围盒 | 78.5410 × 74.6969 mm |
| 面积 | 1913.96 mm² |

包围盒宽 = `2R·sin72° = 78.5410`，高 = `R + R·cos72° = 74.6969`。

## 三、走错的两条弯路（记录备查）

推导过程中先试了两个错误公式，都被数值检查挡下了：

**错误 1：`r = R·cos(2π/5)/cos(π/5)`**
其实这个式子对五角星而言**恰好就是正确答案**（= R/φ²），但当时配的外半径公式
`R = L/(2·sin(π/5))` 是错的，导致边长为 18.54 mm 而非 30 mm。

**错误 2：把内半径当自由参数，用余弦定理解二次方程**
解出 `r = -5.335` 或 `46.626`，都无物理意义——因为这个约束本身是过定的：
内半径由形状决定，不能反过来自由选择。

**正确思路**：先确定"经典五角星"的内外半径比例，再由边长反推尺度。
数值验证：`R·tan36° = 30.000000000`。

**教训**：几何公式必须用数值反代验证。三次推导有两次错，但每次都在
写文件之前被 `expected_edge_mm` 检查拦下——这个断言值得保留在生成器里。

## 五、一个测试缺陷的修正（值得记录）

我最初手写了一个"线段相交"判定来检查自交，结果它报告星形的第 4 条边和
第 7 条边相交。

实际上这两条边**共线但不重叠**——五角星恰好有若干组互相平行、
共线或对齐的边，朴素的方向符号判定会把共线情形误判为相交。

改用 Shapely 后判定为完全有效（`is_valid: True`，非相邻边交点数为 0）。
这再次说明：**几何判定要用经过验证的库，不要手写**。
`validation.py` 现在依赖 Shapely 做多边形有效性检查，这一点在 M2
处理矢量化轮廓时同样需要（轮廓点数上千，手写判定必然出错）。

## 六、代码结构

| 文件 | 职责 |
|---|---|
| `pcbart/shapes.py` | 星形 / 正多边形顶点生成，边长与包围盒计算 |
| `pcbart/generator.py` | `generate_polyline_board` 任意折线板框生成器 |
| `pcbart/validation.py` | 轮廓有效性 + 嘉立创工艺规则校验 |
| `tools/make_star.py` | 五角星命令行生成器 |

`generate_polyline_board` 在写文件前会做三重检查：

1. `expected_edge_mm` —— 等边约束（可选的硬断言）
2. `check_outline` —— 轮廓有效性（自交、退化、最小尺寸）
3. 工艺规则 —— 最小板框 3×3 mm、最小锣边宽 0.2 mm

任一不通过就抛异常，**不会写出一个打不开的板子**。
