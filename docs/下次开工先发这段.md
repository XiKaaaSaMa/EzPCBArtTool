### 截图用真实角色图（2026-09-23 用户要求）

用户点名要用 `P:\PS抠图\由比滨透明背景.png` 重出截图 —— 合成图（"P"）
演示不出板画效果（预览写着「白 3% / 黑 97%」），也看不出异形板的意义。

脚本现在支持 `--image` 指定素材：

```bat
python tools\make_tutorial_shots.py --image "P:\PS抠图\由比滨透明背景.png"
```

**无参数时仍走工具自带的合成图**，这样默认调用不会碰到用户素材。
截图从 7 张加到 8 张，新增 **`08-irregular`（异形板：板框贴着人物轮廓）** ——
这是这工具存在的理由，也是唯一无法从别的截图推断出来的状态。

⚠️ 出图脚本有三处是**硬要求**，改的时候别破坏：

1. **草稿库必须每张截图一个临时目录**，而且要在一个 `window` 内
   在 `build_window()` 之后**立刻 `refresh_draft_panel()`** ——
   两个坑都踩过：不重定向会把开发机真实草稿拍进去；
   八张图共用同一个库，`07-drafts` 存下的那行会留到后面每张图里
2. **`--only` 不能清空输出目录** —— 最初写成先 `rmtree(outdir)`，
   于是只想重出一张就会把另外七张删掉（实测踩到）
3. **风格必须在 `import_to_canvas()` 之前设** —— 风格描述的是
   **下一次导入**；设晚了会出现「预览框是板画、画布还是线稿」的错图

验证：`npm run check` 0 错、`npm run build` 通过；浏览器实机看过渲染，
8 张图全部加载、文章引用与文件一一对应；**390px 手机宽度无横向溢出**。

⚠️ 写文章时踩到的坑：**Markdown 的 `**` 不能跨行**。
「序号列表里换行再收加粗」会被渲染成字面星号，浏览器实测发现的。
已经全篇扫过一遍。
