- 测试 1691 通过、2 跳过。

## 一、为什么做

用户拿 **W（精0，深色立绘）** 实测，两种风格差异巨大：

| 读法 | 墨量 | 结果 |
|---|---|---|
| `fill`（界面默认） | 16.2% | **人物整片涂黑**，衣服线条/腿环/枪全丢 |
| `outline` | 17.6% | 仍是黑块，只多一圈边 |
| **`dodge`** | 11.5% | **纯线条**，细节保留 |

**根因**：W 的不透明区域**平均亮度只有 69.6**（很暗）。
`fill` 按明暗一刀切，深色衣服 + 深色头发整片越过阈值 → 实心黑块。
`dodge` 问的是"这个像素是不是比周围暗"（边缘检测），深色区域内部没有边，
所以不涂黑，只描线。

⚠️ **旧结论已被推翻**：代码注释说 dodge 会让浅色脸消失所以废弃。
实测证明**恰恰相反**——对深色立绘 fill 崩、dodge 好。
正确规则是**按图片明暗选读法**，不是一刀切。

## 二、现状（已核实）

| 项 | 位置 | 现状 |
|---|---|---|
| 读法下拉 | `tools/gui_mockup.py` `READING_OPTIONS` | 只有 `fill` / `outline` 两项 |
| 常量 | 同文件 | 有 `READING_FILL` / `READING_OUTLINE`，**没有 dodge 常量** |
| 参数组装 | `_lineart_params()` | `mode=self._reading()`，已通用 |
| 滑块显隐 | `_refresh_reading_rows()` | 逻辑是"非 outline 就显示粗细/阈值"，**加 dodge 后正好适用** |
| 复位 | `_reset_tuning()` | 读法回到 index 0（fill），滑块复位 100 / 46 |
| 模型层 | `pcbart/lineart.py` | **dodge 完整可用**，`mode="dodge"` 三分支都在 |
| 滑块量程 | `strength` 20–400（默认100）、`threshold` 2–98（默认46） | **已经合适，不用改** |

**死控件问题顺带修好**：界面唯一的 mode 是 fill，而 fill 用 Otsu 定阈值、
不看 strength —— 所以「线条粗细」「墨量阈值」两个滑块**现在点了没反应**。
接回 dodge 后它们才有意义。

## 三、实测过的参数灵敏度（照这个配默认值）

**墨量阈值**（管"选中哪些线"）：

| 阈值 | 墨量 | 墨块数 |
|---|---|---|
| 0.20 | 5.0% | 1208 |
| 0.30 | 7.9% | 971 |
| **0.46** | **11.5%** | **622** |
| 0.65 | 14.1% | 181 |
| 0.85 | 17.7% | 45 |

⚠️ 阈值升高时墨量涨但**墨块数从 1208 掉到 45** —— 细碎线被合并/丢掉。
这是"要细节"还是"要干净"的取舍，必须让用户自己调。

**线条粗细**（`strength`）：0.5→8.6%、1.0→11.5%、1.5→12.6%、3.0→13.6%。
**加粗找不回被阈值丢掉的线**，两者正交。

**默认值建议**：阈值 **0.46**、粗细 **1.0**（即沿用现有滑块默认值，不改）。

## 六、⚠️ 这次不解决的（留给下一轮）

### ✅ 推翻一条旧结论

代码注释里写着「dodge 让浅色脸消失所以废弃」。**实测不成立**：
由比滨（最浅的一张，不透明区亮度 190.4）在 dodge 下**脸和头发轮廓完好**，
眼睛、鼻尖、衣领都在。

⚠️ 旧结论的成因大概是当年**图里还有透明背景没合成**，或阈值/半径没标定。
**那个注释必须改**，否则下一个人还会照着它把 dodge 删掉。

### ⚠️ 但 dodge 有它自己的问题（必须写进界面提示）

由比滨那张 **dodge 出来 2868 个墨块**（W 只有 622），
图上能看到**衣服区域出现大片碎网状杂线**。

原因：浅色区域的明暗变化已经很弱，dodge 的比值响应在噪点上也会翻过阈值，
于是把**纹理噪声**当成线描了出来。这正是「降噪」该出场的地方。

**所以两种读法各有适用范围，不是谁淘汰谁**：

| 图的样子 | 该用哪个 |
|---|---|
| 深色/暗部多的立绘（W、陈） | **dodge（纯线条）** —— 细节全在 |
| 浅色平涂、干净两色线稿 | **fill（填充色块）** —— dodge 会碎 |
| 浅色但想用 dodge | 勾上**降噪**再试 |

⚠️ 界面提示文案要按这个表写，别写成"dodge 全面更好"。

### ✅ 「降噪」确实能压住碎网（已实测）

由比滨（960×1619），dodge 阈值 0.46，只改降噪核：

| 降噪核 | dodge 墨% | 墨块数 |
|---|---|---|
| 0（关） | 4.73 | **2868** |
| 5 | 2.04 | 687 |
| **11** | **1.24** | **32** |
| 21 | 0.82 | 17 |
| 31 | 0.34 | 13 |

**核 11 就把碎网从 2868 压到 32**，而线条还在。所以上面那张表里
"浅色但想用 dodge → 勾上降噪"这条解法是**验证过的**，可以放心写进提示。

⚠️ 量的尺度：短边 960 的 11px ≈ **1.15% 短边**。而现在的自动降噪预设用的是
`SOFT_SHADING_KERNEL_SHARE = 0.65%`（≈6px，只压到 687）。
**这两个数不一样，别搞混**：柔和明暗图要的是 `0.65%`，dodge 碎网要的是 `~1.15%`。
实现时不要为了 dodge 去改那个共享常量——那会连带影响柔和阴影图的现有行为。
