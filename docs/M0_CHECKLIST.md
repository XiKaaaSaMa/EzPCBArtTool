# M0 人工验证清单

离线能做的验证已全部完成（62 项测试通过、三个样本文件回读尺寸精确）。
剩下这几项必须在 EasyEDA Pro 里打开文件确认，因为只有编辑器自己知道
它接不接受我们的写法。

拿到的样本文件在 `out/` 目录：

| 文件 | 内容 | 要验证什么 |
|---|---|---|
| `m0_rect_50x30.epro2` | 50 × 30 mm 矩形板框 | 能否打开、尺寸是否正确 |
| `m0_rect_100x50.epro2` | 100 × 50 mm 矩形板框 | 换一组尺寸，排除巧合 |
| `m0_layers.epro2` | 20 × 20 mm 板框 + 顶层铜填充 | 填充图元与图层表是否正确 |

---

## 检查项 1：能否打开

**操作**：用 EasyEDA Pro 打开 `out/m0_rect_50x30.epro2`。

- [ ] 无报错弹窗
- [ ] 工程出现在工程列表中，名称正确
- [ ] 能进入 PCB 编辑器（不是空窗口，也不是报错页）

**若失败**：记录完整报错文字。同时尝试「文件 → 打开 → 文件源码」看看能否以源码方式加载。
失败信息是定位问题的关键，不要只记"打不开"。

---

## 检查项 2：板框尺寸（最关键）

**操作**：打开 `m0_rect_50x30.epro2`，用测量工具量板框。若工具栏找不到测量，
可用「视图 → 适应板框」后看状态栏坐标，或用标注工具拉一条尺寸。

- [ ] 宽度 = **50.000 mm**
- [ ] 高度 = **30.000 mm**

然后打开 `m0_rect_100x50.epro2`：

- [ ] 宽度 = **100.000 mm**
- [ ] 高度 = **50.000 mm**

**判读方法**：

| 实测结果 | 说明 |
|---|---|
| 尺寸精确 | 单位系数 0.0254 正确，M0 通过 |
| 尺寸是预期值的 **2.54 倍** | 格式其实用 0.01 mm，需把 `EPRU_UNIT_MM` 改成 0.01 |
| 尺寸是预期值的 **10 倍** | 格式其实用 0.01 inch，需改成 0.254 |
| 宽度和高度**数值互换了** | 坐标轴顺序问题 |
| 尺寸正确但**上下颠倒** | Y 轴方向需要去掉取负 |

无论哪种情况，只需要改 `pcbart/units.py` 里的一个常量或
`pcbart/primitives.py` 里的 Y 符号，算法代码完全不用动。改完重新生成再验一次即可。

---

## 检查项 3：板框是否被识别为"板框"

尺寸对不代表编辑器把它当板框——它可能只当成普通折线。

- [ ] 图元显示在 **Board Outline Layer（板框层，紫色）**
- [ ] 执行「适应板框」时视图正好框住这个矩形（说明编辑器认得它是板框）
- [ ] 切换到 3D 预览，能渲染出一块 50 × 30 mm 的板子
- [ ] 板的形状不是自动变成圆形或消失

**若 3D 预览里没有板子**：说明编辑器不认 `POLY` 形式的板框。
解决办法是改用样本工程里的写法——把矩形的 4 条边拆成 4 条独立 `POLY`，
圆角用 `ARC`。这是 M2「异形板框」一定会用到的形式，所以需要提前知道结论。

---

## 检查项 4：铜层填充

**操作**：打开 `out/m0_layers.epro2`。

- [ ] 图层列表中，Top Layer（顶层铜）处于启用状态
- [ ] 能看到一块 10 × 6 mm 的实心填充区域
- [ ] 该填充位于板框内部，左下角距板框左下角 5 mm、7 mm
- [ ] 图元类型显示为「填充 / Fill」，而不是多边形或线条

---

## 检查项 5（可选，但强烈建议）：反向复核

手动画一个已知尺寸的板，再存成 `.epro2`，用我们的工具反向验证——
这能确认我们的实现和编辑器双向一致。

**操作**：

1. 新建工程，在板框层画一个 **25 × 15 mm** 的矩形
2. 另存为 `.epro2`（或「另存为」后从工程目录取文件）
3. 运行：

```
python tools/m0_calibrate.py <你导出的文件>.epro2
```

- [ ] 输出的板框 bbox 宽度为 **25.0000 mm**、高度为 **15.0000 mm**

这一步同时验证了解析器和生成器，是性价比最高的复核方式。

---

## 检查项 6（可选）：官方扩展 API 探路

M0 不依赖插件，但插件是后续 M1–M3 的主输出通道之一，值得提前确认可用性。

**操作**：

1. 在 EasyEDA Pro 里找到扩展 / 插件（高级设置或设置菜单里）
2. 创建一个 Hello World 扩展
3. 尝试调用一个 PCB 图元接口，例如在板框层画一条线：

```js
// 具体命名空间以官方 SDK 为准，参考 https://prodocs.lceda.cn/cn/api/reference/pro-api.html
PCB_PrimitiveLine.create('', 11, 0, 0, 1000, 0, 6, false);
```

- [ ] 扩展能安装并运行
- [ ] 能成功在板框层画出图元
- [ ] 记录下 SDK 版本号

## 反馈方式

把结果告诉我时，重点给这几项：

1. 每个检查项是否通过
2. 任何报错的**完整文字**
3. 若尺寸不对，实测数值是多少

拿到结果后：
- 全部通过 → M0 完成，直接进入 M1（板框绘制 + 图片导入缩放定位）
- 部分失败 → 按上文判读表定位，通常改一个常量即可，改完补一个回归测试再重验
