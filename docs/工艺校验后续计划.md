# 铜层工艺校验后续计划

更新时间：2026-11-04。本文定义后续范围和验收条件，尚未实施。当前修复只补齐板框错误阻断、Gerber 警告传递和测试入口；不据此宣布铜层 DRC 完成。

## 当前基础与缺口

`pcbart/validation.py` 已有板框合法性、板框尺寸和细颈检查，也有显式线宽检查函数。`.epro2` 和 Gerber 导出已有板框检查调用。铜层为 FILL 几何时，图形没有一个可以直接读取的统一“线宽”；线稿处理中的最小特征过滤也不能替代对成品铜几何的校验。

尚未形成闭环的项目是：顶/底铜层局部最小线宽、同层不同铜区的最小线距、铜到板边及挖槽的最小间距。现有常量只作为代码现状，不直接代表所有板材、铜厚与订单选项的制造能力。

## 实施范围

1. 定义可选的工艺规则集，明确单位、板材/铜厚适用范围、规则来源与核实日期。实施前核对制造商当时的能力说明，避免把 0.10 mm 等现有常量扩展为通用承诺。
2. 复用导出实际使用的毫米几何；完成缩放、旋转、翻转、裁切、模板装饰和同层合并后再检查。孔与负形要保留，板框/插舌/挖槽使用最终几何。铜到板边距离按几何边界计算，不能把 Gerber 显示光圈宽度当成成品尺寸。
3. 先定义“违规”的几何含义，再实现测量：局部窄颈/细线、同层分离铜区之间的最近距离、铜边界到成品板边/挖槽边界的距离。为孤岛、孔、尖角、相接或重叠铜区和零面积图形明确口径。
4. 返回结构化问题：规则代码、严重程度、图层、实测值、要求值和可定位区域；区分不能导出的几何错误与需要用户确认的工艺警告。不自动改变用户的线稿或补铜。
5. `.epro2`、Gerber 目录、下单 ZIP 与界面使用同一报告。阻断错误在写出任何新下单文件前处理，警告保留到最后显示；CLI 与界面不能各算一套。

## 验收矩阵

| 项目 | 必测输入 | 验收条件 |
|---|---|---|
| 线宽 | 阈值上下及等于阈值的矩形条、哑铃细颈、带孔铜区、尖角 | 明确边界容差；细线能报出，尖角和有效孔不产生无依据的整图误报 |
| 线距 | 平行条、旋转条、相接/重叠区、孔内铜块 | 只比较同层应分离的铜区；距离在变换、合并后仍正确 |
| 铜到板边 | 矩形、圆弧板框、插舌、异形凹口、模板挖槽 | 包含外边界与挖槽，使用成品边界；定位与毫米测量一致 |
| 完整导出 | 普通线稿、板画、彩印兼有铜装饰、两种通行证 | 两条导出路径报告一致；已有有效工程可导出；不把彩印位图当铜层 DRC 输入 |
| 极端与性能 | 空铜层、纯色、1×1、窄长图、透明图、大图、多对象 | 不崩溃；无铜时报告“无适用几何”；记录耗时及几何数量，预先设定可接受预算 |
| 独立验收 | 输出 `.epro2` 与 Gerber | 第三方回读后复核尺寸、层、孔和违规定位；至少一组在 EDA/制造商 DRC 中对照 |
| 防退化 | 去掉各测量/报告/阻断修复 | 对应行为测试变红，恢复后通过；不只检查内部函数返回 |

每组保留原始输入、规则集、期望值、实际报告、回读结果和局部预览。产物统一放当日 `out/YYYY.M.Dtest/`，临时脚本显式隔离 `PCBART_DRAFTS_DIR`。

## 不在本计划内

SVG 导入按用户决定继续暂停，保存在 `docs/废案.md`。TRACE、通用模板、AI 扩展、重绘工作区并入主窗口、180 px 半身像分别另定需求。本计划不恢复已删除的自动板框开孔，也不承诺检查电气网络、阻抗、叠层或完整制造商 DRC。

## 开工与完成条件

先选定工艺配置和代表性样本，再确定算法及容差；完成验收矩阵、入口一致性、第三方回读和性能记录后，才把路线图改成“已完成”。有未覆盖的几何类型时，在产品导出报告中写明限制。
