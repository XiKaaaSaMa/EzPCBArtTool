# PCB 艺术板工具

**把一张图片，做成能直接下单的 PCB 艺术板。**

导入图片 → 自动提取线稿或转成双色板画 → 套上板框（矩形 / 圆角 / 圆形 /
按图片轮廓的异形板）→ 一键写出**嘉立创 EDA 能打开的工程**和**能直接上传
下单的 Gerber 压缩包**。可以做成挂件、立牌、摆件；线稿能落在铜、丝印、
阻焊任意一层，板画则固定用「白色走丝印、黑色走铜」的双色表达。

整个流程在软件里点着走，参数改一下画布上立刻能看到结果。

> 当前版本 **0.1.2**。
> 安装包在 `安装包保存区\`，源码运行见下面「安装与运行」。

## 现在能做什么

### 导入与出图

| 功能 | 说明 |
|---|---|
| **导入图片** | PNG / JPG 等常见格式，支持透明底色。**中文路径可用**。最长边默认 76.2 mm，可改 |
| **三种风格** | **线稿**（黑白线条）、**板画**（双色块面）、**彩色丝印**（保留原图配色） |
| **板画风格** | 浅色区域白、深色区域黑，外轮廓用白线勾出。分界、轮廓粗细、最小特征、背景填黑、翻转、反相都可调 |
| **实时预览** | 拖动滑块时预览跟着变；大图预览按全分辨率重算 |
| **降噪** | 独立一步，可与线稿分开调、分开看，便于判断是哪一步的问题 |

### 板框

| 功能 | 说明 |
|---|---|
| **四种形状** | 矩形、圆角矩形（圆角半径可调）、圆形、**异形板** |
| **异形板** | 板框 = 图片主体轮廓。三种基础：**原图裁切**、**矩形结合**、**圆角矩形结合**（后两种可调底座高度与图片水平位置） |
| **立牌插舌** | 勾选后在板框下边缘长出一个插舌，接立牌底座。插舌宽高可填（默认 16 × 3 mm，按常见底座插槽定），水平位置用滑块拖 |
| **实时生效** | 板框设置没有「确定/取消」，改一下就变，背后画布就是预览 |
| **包住图片** | 圆形板框直径自动取图片对角线，四个角不会吊在板外 |

### 导出

| 功能 | 产物 | 说明 |
|---|---|---|
| **另存为工程** | `.epro2` | 给嘉立创 EDA 继续编辑：板框 + 铜层 + 丝印层 |
| **另存为下单文件** | **一个 zip** | 里面是板框 + 各层的 Gerber 文件，**直接上传嘉立创下单**，不用再整理 |

Gerber 已用第三方解析器独立复验过尺寸与单位（毫米）；文件是纯 ASCII，
不会被上传解析器认错。

### 界面

| 功能 | 说明 |
|---|---|
| **多工程标签栏** | 像浏览器标签一样同时开好几块板，点着切、✕ 关、`＋` 新开、`Ctrl+Tab` 切换。有未保存改动的标签带一个圆点；切换会记住各自的缩放和位置 |
| **草稿库** | 左侧栏按时间列出，**单击直接打开**；保存 / 改名（点行末 ✎ 就地改）/ 删除 / 新建。退出时若有没保存的活儿会问，**多块板会一块一块问** |
| **图形编辑** | 点选图片、拖动移动、拖四边小三角改尺寸；右侧面板能改位置、尺寸、旋转、翻转、不透明度、所在图层 |
| **图层** | 七个真实图层（正反面铜 / 丝印 / 阻焊 + 板框），颜色与 EDA 里一致。当前层接收新导入的图，隐藏的层不会被误选中 |
| **缩放平移** | 滚轮以指针为锚点缩放、中键或空格拖动平移、【编辑 → 适应窗口】复位 |
| **浮窗** | 预处理 / 板框设置 / 图像预览都是软件内浮窗，可拖边框缩放（四边 + 四角共 8 个可见把手）、可折叠 |

### 性能与健壮性

- **大图不卡**：8K 图导入从 20 秒降到 0.4 秒，异形板描边从 44 秒降到 0.5 秒
- **大图与小图结果一致**：超大图片按受限分辨率计算，同一条线不会因为图变大
  就变细或被滤掉
- **导出的文件经过独立复验**：先写出来、再用另一套程序读回去量尺寸，
  不是只看「能打开」

## 还没做到的

### 界面里还没有的功能

| 缺什么 | 现状 |
|---|---|
| **模板** | 形状下拉里「套用模板」是**置灰的**，点了没用。接口留好了，等确定模板该装什么内容再做 |
| **走线风格** | 铜层目前只有**填充**风格（一块块铺铜）。「走线」风格（骨架化 → 中心线 + 线宽）接口留着，**尚未实现**，现在还调不到 |
| **工艺校验** | 校验代码写好了（最小尺寸、细颈、轮廓有效性），但**导出时还没自动跑**。目前靠导出的文件在 EDA 里能打开来发现问题 |
| **简化容差** | 模型里有这个参数，**界面没有滑块**，暂时只能用默认值 |

### 已知限制

**异形板**

- 只取**最大的一条外轮廓**。图片里分开的部件（飘带、散落的装饰）不会成为
  板框的一部分
- 轮廓**不支持内孔**，环状图形（比如甜甜圈）中间的洞会被填上
- 「结合」模式下如果图片完全飘在底座外面，会得到两块不相连的区域，
  此时**只保留较大的一块**

**图形与工艺**

- 简化产生折线，**没有圆弧拟合**（但圆能被识别成原生 `CIRCLE`）
- 细颈检测有缺口：从厚主体伸出来的细长凸起检测不到
- 最小特征默认 **0.10 mm**，会**削掉线稿里的细发丝**——这是工艺取舍不是
  缺陷，想保细节可以调小（代价是细线可能被蚀刻机印成毛边）
- **边缘不清晰的图，本地描边有上限。** 这种图建议先用别的工具重绘线稿，
  再进本流程

**其他**

- 板框**开孔**（在板子上挖洞）本工具不做，需要的话在 EDA 里自己画
- 安装包**未做代码签名**，首次运行会有 Windows SmartScreen 提示

## 安装与运行

### 用安装包

从 `安装包保存区\公测\PCB艺术板工具_v0.1.1_安装包.exe` 安装。
装完直接启动，**不需要另装 Python 或运行库**。

### 从源码运行

需要 **Python 3.11 或 3.12** 和依赖：

```bat
python -m pip install -r requirements.txt
run.bat
```

`run.bat` 会自动找到本机 Python。双击它也能启动。

### 基本流程

1. 点【打开图片】，选一张图调参数
2. 需要板框就点工具栏【板框设置】选形状、设尺寸
3. 预处理窗里调好后点底部蓝色【导入图片】，图才进画布
4. 【文件 → 另存为下单文件…】写出可直接上传的 Gerber 压缩包

### 命令行

```bat
run.bat test                                    :: 跑测试（878 项）
run.bat outline "图片.png" --width 60           :: 图片 → 异形板框
python tools\make_board_art.py "图片.png" --outdir out --name board --render
run.bat calibrate "路径\到\工程.epro2"          :: 分析工程，自动定标单位与图层
```

```
  primitives.py         图元载荷、路径语法编解码
  geometry.py           复杂多边形绕向规范化（外框 CW、内洞 CCW）
  layers.py             60 条图层定义（实测自 EasyEDA Pro 3.2.149）
  templates.py          工程骨架记录
  image_prep.py         图像去噪、二值化、极性自动判定、主体掩膜
  lineart.py            线稿转换（PS 颜色减淡配方的闭式解）
  denoise.py            降噪（移植自 PCB_lightgraph，MIT）

  outline.py            轮廓提取、简化、轴向吸附、圆识别、工艺补偿

  standee.py            立牌插舌几何
  vectorize.py          掩膜 → 复杂多边形（FILL 已实现，TRACE 预留）
  validation.py         轮廓有效性 + 工艺规则校验
  generator.py          板框生成器 + FILL 写入
  export.py             导出 .epro2
  gerber.py             导出 Gerber + 打包 zip
  draft.py              草稿存取、指纹脏标记、草稿库
  projects.py           多工程工作区模型（纯 Python，可脱离窗口测）
  artboard.py           设计文档模型（板框规格 + 图片放置）

tools/                  命令行工具与界面
  gui_mockup.py         桌面应用主体

  make_board_art.py     命令行出图
  make_outline_from_image.py   图片 → 异形板框
  render_board.py       按原始坐标渲染，校验朝向与几何
  verify_epro2.mjs      独立校验器（Node，不共享 Python 代码）
  acceptance_check.py   端到端验收（两块板跑完整流程 + 重开）

tests/                  878 项测试
out/                    生成的样本与缓存（已 gitignore）
```

## 已确认的格式事实

| 项目 | 结论 |
|---|---|
| 容器 | ZIP：`project2.json` + `<标题>.epru` + `IMAGE/` |
| 日志 | 按行，`{header}\|\|{body}\|`，UTF-8，紧凑 JSON |
| **单位** | **1 单位 = 1 mil = 0.0254 mm**（文件内自证，偏差 0.0000%） |
| 存储精度 | 4 位小数 |
| **Y 轴** | **文件 Y 向上**，与设计坐标系一致（不翻转） |
| 板框 | `layerId = 11`，`POLY` 图元 |
| 板框线宽 | 4.9213 单位 = 0.125 mm |
| 圆形 | `path: ["CIRCLE", cx, cy, r]` 原生形式，无需折线拟合 |
| 填充绕向 | 孔必须与外环**相反**，外环用哪种都行（对照实验实机确认） |
| `LAYER_PHYS.isKeepIsland` | 铜层必须为 `true`，否则编辑器会**静默删掉**孤立铜 |
| 新图元位置 | 必须插在目标文档段内（如 `PCB` 段末尾） |
| 镂空（历史） | layer 11 上的孤立内环**只绘制不切除**（实机确认）——所以本工具不做板框开孔 |

单位系数是**文件内自证**的：样本工程里一条尺寸标注跨 3932.0079 单位，
EasyEDA 自己标注为 `99.873mm`，而 `3932.0079 × 0.0254 = 99.8730`。
详见 [docs/M0_FINDINGS.md](docs/M0_FINDINGS.md)。

⚠️ **规范正文与编辑器实测冲突时，以编辑器写出的数据为准**——已确认四处：
单位系数、Y 轴方向、`PAD` 形状字段形式、`isKeepIsland`。

## 设计原则

1. **内部一律用毫米**，换算只发生在编解码边界，收敛到
   `pcbart/units.py` 里唯一的常量。官方规范正文写的单位（0.01 inch）与真实
   文件相差 10 倍，而因为有唯一常量隔离，修正成本几乎为零
2. **尺寸正确 ≠ 几何正确**——上下翻转和边倾斜都不改变尺寸，
   验收必须包含视觉验证
3. **几何判定用成熟库**（Shapely / OpenCV），不手写
4. **独立的第二实现做校验**，自己写自己读会互相印证错误；
   校验器的覆盖范围就是保护范围
5. **写文件前校验**，把废板挡在生成阶段
6. **先测量再动手**，假设必须用数据验证
7. **不要让界面显示与实际行为不一致**——占位控件看起来能用会误导用户

## 验证

```bat
run.bat test                                    :: 878 项测试
node tools\verify_epro2.mjs out\sample.epro2    :: 独立校验（Node）

```
