# 软件自带素材

`明日方舟-艺术板素材/` 包含干员索引、图标及生成的二维码和条形码。
干员资料与图标来自 PRTS，各文件的来源及相对路径保留在索引中。
`通行证模板源文件/` 是用户提供的两份空白 EDA 模板。

这两份目录随源码和安装包分发，不包含完整立绘、半身像或模型权重。
原始素材库保持独立；此副本仅将说明文档和清单中的本机绝对路径改为相对路径。

程序通过 `pcbart.paths.asset_root()` 只读访问素材。默认路径为源码下的
`assets/`，安装版为 `_internal/assets/`；自定义整份素材库使用
`PCBART_ASSET_ROOT`。生成工具请对可写副本运行，不向安装目录写入。
