## 两个机器码

| | 尺寸 | 载荷 | 模块 |
|---|---|---|---|
| 二维码 | **3.2 × 3.2 mm**（含 4 模块静区） | `i8c.cn/xxxxx`（短链，去掉 `http://`） | v1，29 模块，**0.1103 mm/模块** |
| 条形码 | **39.245 × 4.941 mm**（含两侧各 10 模块静区） | `情报编号`（如 `R001`） | Code 128B，99 模块，**0.3964 mm/窄条** |

二维码尺寸是用户打印实尺样张、手机实扫确认过的：**3.2 mm 可以直接用，不必放大**。

- 文件名用 **`页面名`** 而不是干员名：`暮落` 与 `暮落(集成战略)` 是两位干员，
  页面名才区分得开。
- 两种格式：`.svg` 是 1:1 毫米尺寸（导出走这个），`.png` 是 600 dpi 位图，
  纯黑白二值（丝印印不出灰阶）。
- **24 位干员没有情报编号**，只有二维码：`Mechanist(卫戍协议)`、`Misery(卫戍协议)`、
  `Pith(卫戍协议)`、`Raidian(卫戍协议)`、`Sharp(卫戍协议)`、`Stormeye(卫戍协议)`、
  `Touch(卫戍协议)`、`暮落(集成战略)`、`盟约·辅助干员`、`郁金香(卫戍协议)`、
  以及 13 位`预备干员-*`、`领主·Sharp`。清单在 `_索引\干员码.json` 里。

## 重新生成

```powershell
# 二维码 + 条形码（读完整库，写本库；不会改动完整库）
python tools\build_badge_codes.py --out "assets\明日方舟-艺术板素材"

# 核对图标素材是否齐全（只读）
python tools\build_asset_subset.py --check
```

`build_badge_codes.py` 只写 `20-` / `21-` 两个目录和 `_索引\干员码.json`：
改名或删掉干员后重跑，会清掉自己写的旧文件，不动别的东西。

## 已移除

**立绘、半身像和蚀刻章全部移除**（用户明确不再需要立绘，卡面不再摆放）。

- 旧库 `明日方舟-通行证素材`（3.95 GB）和 `明日方舟-通行证素材-裁切`（1.80 GB）
  已整体停用。
- `明日方舟\`（完整库 4.1 GB）**原样保留不动**，它是重新生成任何子集的来源。
- `tools\crop_figure_library.py` 是给立绘做区域裁切的，现在没有用途，保留作历史记录。
